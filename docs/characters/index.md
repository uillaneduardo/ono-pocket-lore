# Personagens

Catálogo de personagens relevantes para a narrativa e para o cotidiano de Coluna.

Cada personagem deve registrar, no mínimo:

- nome e função;
- setor/local associado;
- motivação;
- relação com Onos;
- conhecimento real sobre a Coluna;
- conhecimento apresentado ao jogador;
- possíveis ganchos narrativos.
