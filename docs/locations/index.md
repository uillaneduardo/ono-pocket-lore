# Locais

Catálogo de locais relevantes de Coluna e do exterior.

## Estrutura sugerida para cada local

- função;
- localização/setor;
- acesso;
- importância econômica;
- NPCs associados;
- recursos e serviços;
- conhecimento público;
- segredos ou spoilers de autor.

Os primeiros locais a documentar devem incluir o Abrigo do jogador, Laboratório Central, Mercado, Centro de Reciclagem e Área Industrial.
