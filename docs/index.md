# Ono Pocket — Lore & World Bible

Esta é a referência canônica do universo de **Ono Pocket**.

O objetivo desta documentação é separar com clareza:

- fatos confirmados do mundo;
- conhecimento disponível à população de Coluna;
- mistérios e hipóteses ainda não resolvidos;
- conteúdo descartado ou substituído.

!!! info "Regra editorial"
    Quando uma ideia ainda não estiver definida, ela deve permanecer marcada como `draft` ou `mystery`. Não transformar hipótese em cânone apenas para preencher lacunas.
